# 记账本 PWA 部署说明

本文件夹是「记账本」的可安装版本（PWA）。部署到任意支持 HTTPS 的静态托管后，
手机可以「添加到主屏幕」像 App 一样使用，电脑可以稳定收藏，数据依然只保存在本机浏览器、端到端加密，不上传任何服务器。

## 文件夹内容
- index.html            主程序
- manifest.json            PWA 配置
- sw.js                 离线缓存（Service Worker）
- icons/                应用图标

## 三种免费部署方式（任选其一）

### 方式 A：GitHub Pages
1. 新建一个 GitHub 仓库（如 ledger）。
2. 把本文件夹（记账本PWA）里的内容上传到仓库根目录（注意 index.html 要在根目录）。
3. 仓库 Settings → Pages → Source 选 main 分支根目录 → Save。
4. 等待几分钟，得到形如 https://用户名.github.io/ledger/ 的网址。
5. 手机浏览器打开该网址 → 菜单「添加到主屏幕」；电脑直接收藏该网址。

### 方式 B：Cloudflare Pages
1. 登录 Cloudflare → Workers & Pages → Create → Pages → 直接拖拽本文件夹上传。
2. 得到一个 https://xxx.pages.dev 网址。

### 方式 C：Netlify
1. 登录 Netlify → Add new site → Deploy manually → 拖拽本文件夹上传。
2. 得到一个 https://xxx.netlify.app 网址。

## 数据迁移
部署后首次打开是空账本。把你现有的数据带过去：
1. 打开旧版（电脑上的 记账本.html），解锁后点「导出加密备份」得到 .json 文件。
2. 打开部署后的网址，点「从备份导入」，选择该 .json 并输入主密码。

## 隐私说明
- 托管的是程序代码，不含任何账目数据。
- 账目数据加密后仅保存在你自己设备的浏览器本地存储中。
- 换设备时用「导出/导入加密备份」迁移，需主密码解密。
