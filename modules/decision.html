决策 · 手册模块规划中

借鉴《高性价比人生指南》的方法论：把每条「要不要做 / 信不信」的事，用同一套字段记下来，沉淀成你自己的决策手册。

决策条目字段（每一条都这样记）

字段说明
条目名称动词开头，例如「报这个课」「换低钠盐」
成本钱 / 时间 / 毅力，各标一档
说人话一句话讲清好处
收益量级大 / 中 / 小
收益口径换寿命 / 钱 / 时间精力 / 自由
证据等级A（有数字可核）/ B（有研究无数字）/ C（经验）
来源原始文献链接或官方出处

三个定位

  • ① 备选单不是任务清单：只挑走一两条，不做没压力
  • ② 成本收益拆解 + 证据分级：用上面字段，别凭感觉
  • ③ 做成 Codex 可查的 skill：AI 先查你的手册再回答

数据原则

  • 数据本地加密存储，归你所有
  • 支持一键导出 / 导入备份
  • 后续接入跨设备自动同步（与记账模块共用同步引擎）
